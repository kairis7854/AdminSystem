# AdminSystem - 後台管理系統

這是一個基於 React 18 + Vite 5 開發的現代化後台管理系統，整合了完整的商品 CRUD 管理流程與權限控制。

## 🚀 專案連結
[點擊查看作品展示](https://admin-system-black.vercel.app)

### 🔑 測試帳號
為了方便快速審閱，請使用以下帳號登入：
- **帳號**：`admin`
- **密碼**：`admin123`

## ✨ 功能亮點
- **商品管理系統**：實作 Mobile 與 Computer 分類列表，支援商品新增、修改、查詢、狀態切換與刪除。
- **權限驗證 (Auth)**：實作 `ProtectedRoute` 路由守衛，確保未授權使用者無法進入後台介面。

## 🛠️ 技術棧
- **前端框架**: React 18 (Hooks)
- **狀態管理**: Redux Toolkit 
- **路由管理**: React Router v7
- **樣式方案**: Tailwind CSS + SCSS
- **UI 組件**: Shadcn UI + Lucide React
- **提示通知**: Sonner 
- **部署平台**: Vercel

## 📦 如何在本地運行
1. `git clone https://github.com`
2. `npm install`
3. `npm run dev`
